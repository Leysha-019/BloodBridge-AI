# BloodBridge AI prototype

## Run
Open `index.html` in a modern browser. No installation is required.

## Demo features
- Dashboard and illustrative low-stock indicators
- Search sample blood-bank records by blood group and area
- Submit a simulated blood request
- View sample inventory
- Preview a donor volunteer form

## Important limitations
This is a front-end student prototype using fictional sample records. It is not connected to live blood banks, hospitals, donors, maps, messaging services, or a trained AI model. The shortage indicators are illustrative threshold labels, not validated AI predictions. Do not use this prototype for real medical or emergency decisions. A production system requires verified integrations, secure backend services, privacy controls, and review by qualified blood-bank professionals.
